## LinkedIn Project Description

**E-Commerce Sales & Customer Analytics | SQL, Python & R**

Built an end-to-end data analytics project analysing 8,000+ e-commerce transactions and 1,000 customers. Used SQL for relational data analysis and business queries, Python (Pandas, NumPy and Matplotlib) for data cleaning, EDA and RFM customer segmentation, and R for statistical correlation and regression analysis.

Key areas analysed:
• Revenue, cost, profit and profit margins
• Monthly sales trends
• Product and category performance
• Regional/provincial performance
• Customer value and RFM segmentation
• Discounting and profitability

The project demonstrates practical skills in SQL, Python, R, data cleaning, statistical analysis, visualisation and translating data into business recommendations.
